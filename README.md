## Fitur

- Kalender mingguan jadwal lab (Senin–Sabtu, 4 sesi/hari)
- Badge status jadwal: Pindah, Tambah, Batal, Ulang, Mingguan, Bulanan
- Admin panel dengan login, CRUD, bulk add, filter, dan export CSV
